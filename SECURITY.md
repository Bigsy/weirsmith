# Security policy

## Supported versions

Security fixes are made on `main` and released in the next package version.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** flow rather than opening a public issue. Include the smallest
reproduction you can, but do not attach proprietary dictionaries or word lists.

If private vulnerability reporting is unavailable, contact the maintainer
through the GitHub profile linked from this repository without including
sensitive details in the first message.
